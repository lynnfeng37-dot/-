# 中国商品期货主力连续合约构建工具 (前复权)
用于处理中国商品期货多合约数据，自动拼接并构建主力连续合约。它采用前复权的方式处理换月缺口，生成平滑的价格序列，适用于量化策略回测和技术指标计算。
## 背景
在期货交易中，主力合约会随着时间推移发生切换（换月）。由于不同月份合约受持有成本、季节性等因素影响，价格通常存在价差。直接拼接会导致价格序列出现人为的跳空，严重失真，影响以下应用：

1.技术指标计算：如 MA、MACD、RSI、ADX 等依赖价格连续性的指标。

2.策略回测：不仅导致信号误触发，还会影响盈亏计算的准确性。

本项目通过价差法对历史数据进行前复权修正，消除换月缺口。
## 功能
1.自动识别主力：基于每日持仓量最大原则，动态筛选每日的主力合约。

2.智能换月检测：自动识别主力合约切换的日期。

3.前复权处理：采用价差调整而非比率调整，保留了价格的绝对变动幅度。逻辑：调整后价格 = 原始价格 + 累积换月缺口。保持最新价格为真实市场价格，向历史方向修正。

4.数据清洗：自动处理中文字段名、千分位符、日期格式转换。
## 适用场景 & 市场
中国商品期货市场 (DCE, SHFE, CZCE, CFFEX, INE)。

适合豆粕、螺纹钢、铁矿石等绝大多数存在期限结构的品种。
## 适用策略

CTA 趋势跟踪策略。

技术分析：依赖价格形态和指标的策略。

注意：由于采用了价差调整，历史价格可能出现负值（在长期贴水结构下），如果策略依赖价格的比率（如计算涨跌幅百分比），请谨慎使用或改用比率复权法。
